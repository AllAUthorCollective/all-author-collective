DESIGN PHILOSOPHY:
- Ultra-premium, sophisticated, and high-end (think: Apple meets Penguin Random House meets high-end literary agency)
- Use a warm but professional color palette: deep charcoal (#1a1a1a), rich burgundy (#6b1d2b), warm gold/amber (#c9a84c), cream/off-white (#faf8f5), and dark charcoal (#2d2d2d)
- Typography: Use a serif font for headings (Playfair Display or similar) to evoke the literary world, and a clean sans-serif for body text (Inter or similar)
- Generous whitespace — create breathing room
- Subtle animations on scroll (fade-in, slide-up, parallax effects)
- Glass-morphism elements for modern, premium feel
- Mobile-first, fully responsive
- Dark mode toggle option (premium feature)
- Smooth micro-interactions (hover effects, transitions)
- Custom cursor or subtle cursor effects (optional premium touch)
